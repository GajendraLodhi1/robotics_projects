# Track 1 ROS 2 web teleoperation

**Upstream author:** [weepwood/RoboPilot](https://github.com/weepwood/RoboPilot), MIT licensed. `upstream_robopilot/` is a pinned Git submodule. It is reference code, not Gajendra's implementation.

Start with the [DOCX guide](reports/ros2_web_teleoperation_study_guide.docx) or [PDF guide](reports/ros2_web_teleoperation_study_guide.pdf). The guide maps the ROS 2 and Gazebo data flow, gives Windows 11 plus WSL2 setup checkpoints, and proposes a new robot-side command timeout and telemetry logging project for later independent work.

Use [progress_log.md](progress_log.md) to record what you personally ran and observed. A completed log and your own code changes can support a later original portfolio project; this folder alone is a study reference.
