# Track 2 ArUco camera pose estimation

**Upstream author:** [Hydran00/aruco_camera_pose_estimator](https://github.com/Hydran00/aruco_camera_pose_estimator), MIT licensed. `upstream_aruco/` is a pinned Git submodule. It is reference code, not Gajendra's implementation.

Start with the [DOCX guide](reports/aruco_camera_pose_study_guide.docx) or [PDF guide](reports/aruco_camera_pose_study_guide.pdf). The guide explains the camera matrix, marker detection, the camera-to-world transform, the ROS 2 service, and a measurable validation experiment. It also points out configuration values that must be replaced for your own camera.

Use [progress_log.md](progress_log.md) to record what you personally ran and observed. The guide proposes a separate calibration quality checker as a later original project.
